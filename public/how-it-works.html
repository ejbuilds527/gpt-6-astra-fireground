The model proposes the side. Code verifies it does not cross. A crossing sends it back — that loop is the adversarial review, and it is the part worth watching.
An honest gap. There is no vector driveway. OpenStreetMap tags them highway=service, service=driveway, and the Connecticut extract is not loaded. So today the driveway is the model reading imagery, and 823 ft is a routed road distance used as an upper bound rather than a traced centreline.
